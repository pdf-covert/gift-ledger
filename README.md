# 人情录

fnOS(飞牛OS)人情账本应用:记录婚礼、满月、生日、乔迁、升学、白事等场合的礼金往来,让每一份心意有迹可循。

> 本仓库用于**应用介绍**与**版本发布**:从 [Releases](https://github.com/pdf-covert/gift-ledger/releases) 下载 `.fpk` 安装包,在飞牛OS 应用中心手动安装即可。应用源码托管在自建 Git 服务。

## 功能特性

- **记账简单**:「记一笔」收录入/支出,选关系、事由、日期,一键保存;随时查看、编辑、删除
- **往来汇总**:按联系人聚合收支,结余一目了然,该回多少心里有数
- **统计分析**:最近 6 个月收支趋势折线图、支出事由分布环图
- **筛选查找**:按姓名/备注搜索,按事由、月份筛选,收支类型分页浏览
- **多账户隔离**:每个飞牛账户独立账本,家人各记各的账,免登录自动识别身份
- **数据本地**:账本以 SQLite 存储在 NAS 本机,不经第三方,不上云
- **加密备份**:全量数据一键导出为 AES-256-GCM 加密文件,密钥仅存本机;导入自动解密恢复

## 安装

1. 在 [Releases](https://github.com/pdf-covert/gift-ledger/releases) 页找到最新版本
2. 根据飞牛OS 设备架构下载安装包:
   - `gift-ledger-x86-<版本>.fpk` —— x86_64(amd64)
   - `gift-ledger-arm-<版本>.fpk` —— ARM64
3. 打开飞牛OS **应用中心 → 手动安装**,选择下载的 `.fpk` 文件
4. 安装完成后从桌面进入「人情录」

> 应用通过 fnOS 统一网关访问(免独立端口、免登录);桌面入口对所有用户可见,每位家人有独立账本。

## 数据与隐私

- 账本数据仅存储在飞牛设备本地(`<pkgvar>/data`),卸载应用前建议先在「设置」页导出备份
- 备份文件为 AES-256-GCM 加密,加密密钥随机生成、仅保存在本机服务端,**备份文件只能在导出它的那台设备上导入**
- 会员状态(限免/永久)保存在开发者云端,仅用于支持持续更新,与账本数据无关

### 发版流程(维护者)

```bash
# 1. 在源码仓库打双架构安装包(产物 gift-ledger-x86-<版本>.fpk / gift-ledger-arm-<版本>.fpk)
cd fnapp && ./scripts/package.sh

# 2. 草拟发布说明后创建 Release 并上传安装包
gh release create v1.0.0 ../fnapp/gift-ledger-x86-1.0.0.fpk ../fnapp/gift-ledger-arm-1.0.0.fpk \
  --title "人情录 v1.0.0" --notes "首发版本。"
```
